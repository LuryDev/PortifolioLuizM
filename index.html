Olá! Meu nome é Luiz Miguel, tenho 17 anos e estudo Informática para Internet na Etec de Praia Grande. Programo há cerca de 5 anos: comecei com Python e hoje me dedico ao desenvolvimento web, com foco em back-end e banco de dados.

Projetos

Aprovado na Seletiva Azul2026

DelayTrack

Sistema web que define os motivos dos atrasos de voos. Ele separa o atraso que começou o problema dos atrasos que vieram em cascata e mostra a causa raiz em todos os voos afetados.

  • Área da operação, com login por código de funcionário, e área do passageiro, que acompanha os próprios voos.
  • Regras de negócio no PostgreSQL, com funções SQL, consultas recursivas e controle de acesso por perfil.
  • Sugestão automática do motivo do atraso com machine learning (Naive Bayes), que aprende com os motivos confirmados.
  • HTML
  • CSS
  • JavaScript
  • PostgreSQL
  • Supabase
  • Vercel
